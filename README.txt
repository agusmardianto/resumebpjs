RESUME MEDIS BPJS - RESUME RAWAT INAP
======================================

ISI FOLDER
- index.html : struktur formulir
- style.css  : desain layar dan tata letak cetak A4
- script.js  : tombol cetak, tanggal otomatis, dan kosongkan form

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder resume_medis_bpjs.
3. Klik dua kali index.html atau buka dengan browser (Chrome/Edge/Firefox).
4. Isi data pada formulir.
5. Klik "Cetak / Simpan PDF".
6. Pada dialog cetak, pilih printer atau "Save as PDF".
7. Pilih kertas A4, orientasi Portrait, dan skala 100% / Default. Jika browser
   menambahkan margin, pilih margin "None" atau "Default" sesuai pratinjau.

CATATAN
- Tidak menggunakan database dan tidak mengirim data ke server.
- Data formulir tidak tersimpan permanen. Simpan/cetak sebelum menutup atau
  memuat ulang halaman.
- Desain dibuat mengikuti susunan pada foto sebagai template digital. Logo BPJS
  dibuat sebagai teks/ornamen sederhana, bukan file logo resmi. Untuk penggunaan
  resmi, sesuaikan logo, redaksi, dan tata letak dengan formulir resmi fasilitas
  kesehatan serta ketentuan BPJS yang berlaku.
- Pada bagian Cara Keluar, pilih satu opsi; pilihan terpilih akan diberi lingkaran
  pada layar dan hasil cetak di browser modern.
